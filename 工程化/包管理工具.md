
**概念**

包管理工具是软件开发中用于自动化管理依赖项、库和模块的核心工具，它能帮助开发者高效处理代码复用、版本控制和环境配置等问题

| **工具**   | **特点**                                  | **适用场景**       | **核心命令**                     |
| -------- | --------------------------------------- | -------------- | ---------------------------- |
| **npm**  | 全球最大 JS 包仓库，生态丰富，Node 默认集成              | 通用前端项目         | `npm install` `npm publish`  |
| **yarn** | 速度更快，支持离线模式和工作区（Workspaces），Facebook 主导 | 多包管理（Monorepo） | `yarn add` `yarn workspaces` |
| **pnpm** | 采用硬链接减少磁盘占用，依赖树更扁平，性能最优                 | 大型项目性能优化       | `pnpm install` `pnpm link`   |
| **cnpm** | 淘宝 NPM 镜像，解决国内下载慢问题                     | 国内网络环境下的快速安装   | `cnpm install`               |
